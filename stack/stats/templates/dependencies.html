Not saved. Fix these lines:

    One requirement per line, as in a pip requirements file; # starts a comment. Packages already in the image (numpy, pandas, matplotlib, scipy, ipywidgets, jupyter…) are kept at their pinned versions: a line that needs another version of one of them fails instead of replacing it.

    Examples

    Plain packages from PyPI, optionally with a version:

    rich
polars>=1.0
scikit-learn

    PyTorch, CPU only (about 200 MB to download). An index option must stand on a line of its own (pip ignores it next to a package) and then applies to the whole file, so every package listed is looked up on the PyTorch index only:

    --index-url https://download.pytorch.org/whl/cpu
torch

    To mix the CPU build with packages from PyPI, add the PyTorch index as an extra one and pin the +cpu build (the current version is listed on download.pytorch.org):

    --extra-index-url https://download.pytorch.org/whl/cpu
torch==2.14.0+cpu
rich

    PyTorch with CUDA for the NVIDIA GPU: the default build from PyPI bundles the CUDA libraries, about 3 GB to download and more on disk:

    torch

    Not allowed, because they would install outside the managed environment or read other files: -r, -c, -e, --target, --prefix, --root, --user, --src.
